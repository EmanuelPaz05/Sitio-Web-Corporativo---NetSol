## Sobre las presentaciones

- **NetGestión**: producto comercial utilizado por más de 30 clientes, desarrollado desde NetSol.
- **ISCP**: proyecto vinculado a instituciones educativas; presentación dirigida a **colegios secundarios en general**, no sólo a un establecimiento. Los módulos técnicos específicos deben documentarse con material aprobado del sistema.
- **Municipalidades y comunas**: soluciones institucionales y servicios técnicos de NetSol, adaptados a cada organización. No se atribuyen implementaciones concretas sin evidencia pública.
- **CRAF**: sistema web para administrar pacientes, planes, sesiones, caja y reportes; el código original permanece privado.
- **OptiNet**: SaaS para ópticas en desarrollo; se diferencia el MVP documentado de las funciones previstas.
